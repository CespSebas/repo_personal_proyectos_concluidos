# Análisis de datos de ventas retail

**Código:** privado (prueba técnica)
**Tipo:** análisis de datos · **Estado:** concluido

## Resumen

Análisis exploratorio de ventas de una cadena de retail para responder preguntas de negocio con SQL y estadística.

## Funcionalidad

- Estacionalidad de ventas por formato de tienda
- Análisis de Pareto (concentración de ventas)
- Cohortes de retención
- Detección de quiebres de inventario por categoría
- Evaluación de un experimento A/B con diferencias en diferencias

## Stack

Python · DuckDB (SQL) · SciPy · Matplotlib · Jupyter
