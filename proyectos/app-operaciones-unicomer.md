# App de Operaciones — Unicomer

**Código:** privado (propiedad de la empresa)
**Tipo:** aplicación web full-stack · **Estado:** en curso (práctica profesional)

## Resumen

Migración de una aplicación interna de operaciones, construida en Power Apps, a una arquitectura web con frontend, API REST y base de datos propias.

## Funcionalidad

- Evaluaciones operativas a partir de plantillas configurables y versionadas
- Calificación ponderada calculada automáticamente
- Evidencias, comentarios y firmas por evaluación
- Usuarios con múltiples roles y autenticación por token
- Bitácora de auditoría

## Stack

Angular · TypeScript · Java 21 · Spring Boot · Spring Security (JWT) · Spring Data JPA · PostgreSQL · Flyway

## Prácticas aplicadas

Arquitectura modular por dominio, migraciones versionadas de base de datos, errores y paginación estandarizados, y Merge Requests con revisión de código antes de integrar a la rama principal.
