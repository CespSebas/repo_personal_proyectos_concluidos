# Comercializadora Caces de Oro

**Código:** público → [CespSebas/comercializadora-caces-de-oro-showcase](https://github.com/CespSebas/comercializadora-caces-de-oro-showcase)
**Tipo:** sitio web · **Estado:** concluido

## Resumen

Sitio web de catálogo para una empresa de productos alimenticios y su marca asociada.

## Funcionalidad

- Página principal con catálogo de productos
- Sub-sitio independiente para la marca asociada
- Catálogo descargable en PDF
- Componentes reutilizables (encabezado, pie de página, contacto)

## Stack

HTML5 · CSS3 · JavaScript
