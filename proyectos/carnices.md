# Carnices

**Código:** público → [CespSebas/carnices-showcase](https://github.com/CespSebas/carnices-showcase)
**Tipo:** aplicación web full-stack · **Estado:** concluido

## Resumen

Sistema de gestión para un emprendimiento: catálogo de productos, pedidos y reseñas, con vista de cliente y panel administrativo.

## Funcionalidad

- Catálogo de productos con categorías y etiquetas
- Registro y seguimiento de pedidos
- Reseñas de productos
- Gestión de imágenes de producto

## Stack

Angular · TypeScript · Node.js/Express · Prisma ORM · MySQL
