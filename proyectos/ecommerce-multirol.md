# E-commerce con panel multi-rol

**Código:** privado (proyecto universitario)
**Tipo:** aplicación web full-stack · **Estado:** concluido

## Resumen

Portal de comercio electrónico con panel administrativo y roles diferenciados, optimizado para SEO.

## Funcionalidad

- Catálogo de productos y gestión de pedidos
- Autenticación JWT con múltiples roles
- Panel administrativo
- Despliegue con contenedores Docker

## Resultado

Catálogo 60 % más ágil y despliegue reducido de horas a menos de 10 minutos.

## Stack

Angular 17 · NestJS · TypeScript · Prisma ORM · MySQL · JWT · Docker
