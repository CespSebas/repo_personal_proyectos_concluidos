# Motor de reglas de promociones

**Código:** privado (proyecto personal)
**Tipo:** aplicación de escritorio · **Estado:** concluido

## Resumen

Motor de reglas para gestionar las promociones de una cadena de supermercados, que reemplazó un proceso manual en hojas de cálculo.

## Funcionalidad

- Definición y validación de reglas de promoción
- Reportes de margen para detectar errores de precio antes de llegar al piso de venta
- Interfaz de escritorio pensada para el equipo de operaciones

## Resultado

Errores de precio detectados un 40 % más rápido; la herramienta se adoptó sin capacitación formal.

## Stack

C# · .NET Framework 4.8 · SQL Server 2019 · WinForms · Repository Pattern · Unit of Work
